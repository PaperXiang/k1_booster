## 1. 追球提速（对应 `追球对比_v1_5_vs_v1_6.md` 文档）

**背景**：对比文档指出 1.6 追球"慢、犹豫、先转再走"，根因是 `SimpleChase::tick()` 回退成了无前向保底的精简公式，叠加转速上限被砍。

| 位置 | 原先 | 现在 | 含义 |
|---|---|---|---|
| `config.yaml` 全局限速 | vx 1.2 / vy 0.5 / vθ 1.5 | **vx 2.0 / vy 0.8 / vθ 2.4** | 退回 1.5 时代的值，全场移动整体放开 |
| `chase.xml` 的 SimpleChase | 用节点默认(0.6/0.2)，无 vθ 端口 | 显式 `vx_limit=1.4 vy_limit=0.4 vtheta_limit=2.4` | 给追球直接放开限速 |
| `brain_tree.h` SimpleChase 默认端口 | vy 0.2 / vx 0.6 | vy 0.4 / vx 1.2，新增 `vtheta_limit=2.4` | 节点默认值同步抬高 |
| `brain_tree.cpp` `SimpleChase::tick()` 公式 | 单一 sigmoid `linearFactor`，球在侧前方时前向≈0（只原地转） | **距离 ramp（`rampDist=0.6` 内线性减速到 0）× 朝向因子 `√cos(yaw)`** | 中小偏角仍保留大部分前向速度→边走边转走弧线，接近 90° 才退化为原地转 |

**对比原先的本质**：旧公式 `1/(1+exp(3·range·|yaw|−3))` 只看"距离×偏角"，球一偏就把前向压到 0；新公式把"距离衰减"和"朝向衰减"解耦，远处全速、近处平滑刹停、偏角用开方放缓，所以追得更直接。

**风险（中）**：
- 全局 `vx_limit` 1.2→2.0 **影响所有走路/起身/站位**（不只追球）。这是本次最大的稳定性变量——**跑得快=更容易摔/过冲/定位漂移**。
- `rampDist=0.6`、`√cos` 增益是经验值，需实测。
- 缓解：若摔倒多，先把 `config.yaml` 的 `vx_limit` 往回收（如 1.6），`SimpleChase` 的 `vx_limit=1.4` 单独保留即可。

> **重要补充（今日跟进）**：0618 的追球提速**只改了 `SimpleChase`**，而 `SimpleChase` 仅用于 `chase.xml`（`scripts/chase.sh`）和手柄 `assist_chase` 分支——**自动比赛（`game.xml`→StrikerPlay/GoalKeeperPlay）用的是另一个节点 `Chase`，0618 没碰它**。即"边走边转走弧线"的改进当时**没进比赛**。今日已把同样的 `√cos` 朝向因子补进 `Chase::tick()`（`brain_tree.cpp`），用新端口 `arc_walk` 门控（节点默认 `false`=原 `sigmoid` 行为；`subtree_striker_play.xml` / `subtree_goal_keeper_play.xml` 里设 `arc_walk="true"` 开启）。**回退**：把这两处 `arc_walk` 改回 `"false"` 即可（只需重装 XML，不必重编 C++）。`vx_limit` 按要求未动。

## 2. 主动找球重写（移植 1.5 的连续扫描，对应 `ball_search_and_head_motion` 文档）

| 位置 | 原先(1.6) | 现在 | 含义 |
|---|---|---|---|
| `subtree_find_ball.xml` | `Sequence`：快扫→原地转180°→快扫→回位等 **5s**（头身**交替**） | `ReactiveFallback`：发现球即退出 + `Parallel(CamLissajousScan ∥ RobotFindBall)`，放弃等待降到 **2s** | 头身**并行**、边转边扫、发现即收敛 |
| `CamLissajousScan` 节点 | **不存在** | **新增，已实现并注册**（`brain_tree.cpp:45`） | "竖快横慢"椭圆扫描，pitch 周期与身体转身解耦，修复"半圈只扫上半椭圆"漏球问题；`yaw_amplitude=0.9`（比 1.5 的 1.012 更贴合头部 DOF 限位） |
| `RobotFindBall` 节点 | 只原地自转 | 加 `transition_vx` 前进衔接、稳定检测去抖（连续 3 帧才提速）、队友球位转向、退出时主动停身 | 找到球能平滑接追球，可借队友信息 |

**评价**：实现完整、节点已注册、与文档建议一致。**风险低**。注意找球时身体会前进+转圈，确认不会走出场/撞人。

## 3. ✅ 新增独立包 `k1_teammate_ball`（高置信度队友球共享）

**唯一一个"独立成 package + 完整接 config"做对的功能，可作为后续模板。**

- **新包** `src/k1_teammate_ball/`：纯 C++ 逻辑库（**不依赖 ROS / brain 类型**），`package.xml` + `CMakeLists.txt`（ament_cmake，导出 target），含 `BallReport` / `FusedBall` / `Config` + 类 `TeammateBallSharing`(`shouldShare`/`ingest`/`fuse`/`reset`)。
- **接入 brain**：`package.xml` 加 `<depend>`、`CMakeLists.txt` 加 `find_package` + `ament_target_dependencies`、`brain.h` 持成员、`brain_config.h` 加 7 个字段、`config.yaml` 新增 `teammate_ball_share`（7 项）、`brain.cpp` declare/get_parameter + init + `handleCooperation` 融合。
- **逻辑含义（对比原先）**：旧逻辑只按"检测到 + 距离最近"选队友球；新逻辑加**置信度门控**（≥50 才采信）、选**置信度最高**者、超时保持。传输仍复用现有 `enable_com` 的 UDP，不新开 socket。
- **默认 `enable: false`** → 关闭时**完全走原逻辑**，零行为变化。

**风险（低）**：默认关。打开后改变队友球采信策略，需验证 `min_confidence_to_trust=50` 是否合理。

## 6. ❌→✅ 启动崩溃问题（本次已修复）

**问题**：`game.xml` 通过 `<include>` 加载 `subtree_locate.xml`，而该文件第 7-8 行引用了 `SelfLocateCircle` / `SelfLocatePenalty`：

- 全仓库 `src/**/*.cpp,*.h` 中**无这两个类的声明、实现，`REGISTER_BUILDER` 列表里也没有**。
- BTCPP v4 在 `registerBehaviorTreeFromFile` / `createTree("MainTree")`（`brain_tree.cpp:91-92`，启动期 `Brain::init()` 内）做 XML 校验时遇到未注册节点会**直接抛异常 → brain_node 启动即崩**。
- 影响面：`game.xml` / `demo.xml`（凡 include locate 的）全部加载失败。`chase.xml` 不含 locate，所以 `scripts/chase.sh` 不受影响——这就是为什么用追球树调试时没暴露。
- 历史错误来源：`定位策略分析.md` 当时的 §12 把这两个节点描述为"已实现并注册"，但 0618 当时**实际代码没有**；当前该文档已更新为说明 0618 删除错误 XML 引用、0619 实现 `SelfLocateCircle` 但默认不挂级联。

**本次修复**：删除 `subtree_locate.xml` 中那两行 → 恢复为原有的 `SelfLocate*` 平移校正级联，比赛树可正常加载。

> 若日后真要这个"全位姿（含朝向）校正"功能，需按 §12 真正在 `brain_tree.h` 声明、`brain_tree.cpp` 实现、`REGISTER_BUILDER` 注册 `SelfLocateCircle`/`SelfLocatePenalty`，并修复 `SelfLocate2X` / `_doubleX` 的 `(p1+p1)/2` 笔误后再接回 XML。

## 8. 赛场测试建议（按风险排序）

1. **【上场前必做】构建+起树**：机器人/容器内 `colcon build --packages-select k1_teammate_ball brain`，再 `ros2 launch brain launch.py tree:=game.xml` 确认**能正常起来不崩**（崩溃已修，但务必复验）。这一步挡住绝大多数事故。
2. **追球提速**：先 `scripts/chase.sh` 空场跑——看是否还"先转后走"、近球会不会冲过球（调 `rampDist`/`stop_dist`）；再上 `game.xml`，**重点看全局提速后走路/起身/站位会不会摔**（vx 2.0 是最大变量）。摔得多就回收 `vx_limit`。
3. **找球**：把球放机器人身后/侧后，触发 `decision=='find'`，确认转一圈内**必扫到球**、发现即停、不出界。
4. **队友球共享**：默认关=无变化。要测就单独开 `teammate_ball_share.enable:true`（保持 `enable_com:true`），两台机一台遮球一台看球，看遮球方日志 `[tmBallShare] reliable tm ball ...` 是否采信，50 门控是否过严。
5. **拦截 / 守门扑救**：**本次别测**——已删除/未接线，测了也不触发。
6. **赛前清单**（见 `比赛流程分析.md` §12）：`team_id=66`、`player_id`、`player_role`、`player_start_pos`、`game_control_ip`、`treat_person_as_robot=false` 逐项确认。
